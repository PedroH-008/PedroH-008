## 📌 Projetos em destaque

### 📦 Sistema de Gerenciamento de Estoque

Sistema web para controle de produtos, funcionários, vendas e registros de ações. O projeto trabalha com backend em Node.js, rotas REST, banco de dados MySQL e organização por módulos.

**Principais recursos:**

- Cadastro, listagem, edição e exclusão de produtos
- Controle de funcionários
- Registro de vendas
- Atualização automática de estoque
- Histórico de logs das operações
- Integração com banco de dados MySQL

**Tecnologias utilizadas:**  
Node.js, Express, MySQL, JavaScript, HTML, CSS

---

### 💰 Aplicativo de Gestão Financeira

Aplicação mobile para controle financeiro pessoal, permitindo cadastro de transações, categorização de gastos e visualização de dados em dashboard.

**Principais recursos:**

- Cadastro de receitas e despesas
- Autenticação de usuários
- Integração com backend em nuvem
- Persistência de dados
- Dashboard financeiro
- Organização por categorias

**Tecnologias utilizadas:**  
React Native, Expo, AWS Lambda, API Gateway, DynamoDB, Cognito
